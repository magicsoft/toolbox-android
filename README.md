Android utility app with a built-in **free VPN**. Import YAML VPN configs, manage nodes and rules, and keep everyday phone tools in one place.

## VPN (main)

- Start / stop the system VPN (free VPN)
- Import a local YAML config (`.yaml` / `.yml`)
- Add a profile from a subscription / config URL
- Switch among multiple profiles
- Nodes, groups, and rules in the YAML (domain, IP, and similar routing)
- Save a profile before activating it
- Optional **daily auto-update** of bundled nodes
- One-tap refresh when you need a newer node list

You can import your own `config.yaml` via **Profiles → New / Import**, or paste a config URL.

## Other tools

- Device info: CPU, battery, storage, network
- QR, PDF/image convert and compress
- Wallpapers, GIF, blur, watermark removal
- Browser utilities, IPTV helper, Morse, lucky wheel

## Requirements

- Android 6.0 or newer
- VPN permission when you turn the VPN on
- Allow install from this browser / file manager

# 设备管家 3.3.7

内置 **免费 VPN**。支持导入 YAML 配置文件、规则分流，并附带常用手机工具。

**包名：** `zzy.cpucooler.google`  
**版本：** 3.3.7（32115）

## VPN（重点）

- 一键开启 / 关闭系统 VPN（免费的vpn）
- 从本地导入 **YAML 配置文件**（`.yaml` / `.yml`）
- 用 **订阅地址 / 配置 URL** 添加配置
- 多配置文件切换
- 支持 YAML 里的 **节点、策略组、规则**（域名、IP 等分流）
- 激活前可保存配置
- 可选 **每天自动更新** 内置节点
- 需要时手动刷新节点列表

在应用里打开 **配置 → 新建 / 导入**，选择本地 `config.yaml`，或填写订阅 / 配置 URL。

## 其他工具

- 设备信息：CPU、电池、存储、网络
- 二维码、PDF/图片转换与压缩
- 壁纸、GIF、模糊、去水印
- 浏览器工具、IPTV、摩尔斯电码、幸运转盘

## 系统要求

- Android 6.0 及以上
- 开启 VPN 时需要系统 VPN 授权
- 允许当前浏览器或文件管理器安装未知应用
